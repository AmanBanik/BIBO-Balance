# Subagent: RL

## Mission

Develop the learned controller without corrupting the physical environment.

## Deliverable

- observation definition;
- action scaling;
- reward terms;
- algorithm candidate;
- rollout design;
- evaluation distribution;
- robustness curriculum;
- reproducibility record.

## Required experiment progression

privileged state → phase/state → vision → disturbances → physics-informed extension.
