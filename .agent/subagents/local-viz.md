# Subagent: Local Visualization

## Mission

Build the laboratory application using C++/OpenGL/Dear ImGui.

## Required visual objects

- platform;
- ball;
- four rods;
- joints;
- world axes;
- platform axes;
- gravity vector;
- platform normal;
- projected gravity;
- velocity;
- trajectory;
- energy/telemetry plots.

## Rule

Procedural geometry is preferred. Do not introduce Blender as a runtime dependency without explicit architectural approval.
