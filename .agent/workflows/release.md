# Workflow: Release

## Gate

- build clean;
- unit tests pass;
- deterministic regression passes;
- CPU/GPU parity verified when applicable;
- state schemas current;
- docs current;
- no secrets;
- reproducibility metadata present;
- known limitations documented;
- public demo artifacts checked.

Release notes must distinguish:

- implemented;
- measured;
- experimentally observed;
- intended/future.
