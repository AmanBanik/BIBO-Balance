# Documentation and State Rules

Update project state when:

- architecture changes;
- contracts change;
- an open decision is resolved;
- a major benchmark is completed;
- a known failure mode changes;
- an experiment invalidates a prior assumption.

Do not over-document implementation trivia.

The master specification contains architecture and design intent.

README should contain engineering/reproduction information.

The scientific paper should contain the scientific model and evaluation, not source-code plumbing.
