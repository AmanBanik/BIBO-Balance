# RL Rules

- Start with the simplest observation space that can prove controllability.
- Keep physics deterministic during baseline debugging.
- Record every environment distribution.
- Separate training and evaluation.
- Avoid privileged information in vision experiments.
- Penalize violent actuator behavior through the reward or action constraints when appropriate.
- Measure recovery time and stable-window duration, not reward alone.
- Introduce disturbance complexity progressively.
- Never call a system PINN merely because it contains a neural network and physics.
